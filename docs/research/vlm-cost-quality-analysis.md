# Вибір VLM для читання креслень: аналіз вартості та якості

Станом на серпень 2026 року. Джерела: [OpenRouter API](/моделі), [Z.ai документація](https://docs.z.ai/guides/overview/pricing.md).

## Коротка відповідь

**Не купуй Z.ai за $18/міс** — це підписка *на кодування* (Claude Code, Cline), а не для загального чату чи API. Дешевша та краща стратегія:

1. **Спочатку безкоштовно**: Z.ai GLM-4.6V-Flash або Gemma 4 31B через OpenRouter — перевірте, чи витримує якість ваші креслення.
2. **Якщо не витримує — найдешевший платний**: Z.ai GLM-4.6V-FlashX ($0.04/0.40 за 1M токенів) або Gemini 2.5 Flash Lite ($0.10/0.40).
3. **Якщо потрібна Claude-якість**: користуйся Claude **API** ($3/15 за 1M), а не Pro-підпискою. Без лімітів, платиш за використання.
4. **Якщо хочеш GPT Plus**: GPT-5 mini ($0.25/2.00) — ти вже платиш за Plus, просто перемкнися на API.

## Як налаштувати у FreeCadCopilot

Додаток підтримує провайдерів через LiteLLM. Для Z.ai або OpenRouter вибирай **"Custom/Local"** у налаштуваннях і вкажи:

| Провайдер | Base URL | API Key |
|---|---|---|
| Z.ai | `https://api.z.ai/v1` | [Z.ai API key](https://z.ai/model-api) |
| OpenRouter | `https://openrouter.ai/api/v1` | [OpenRouter key](https://openrouter.ai) |
| DeepSeek | `https://api.deepseek.com/v1` | [DeepSeek key](https://platform.deepseek.com) |

Потім у випадаючому списку моделей вибирай, наприклад, `glm-4.6v-flash` або `z-ai/glm-4.6v`.
