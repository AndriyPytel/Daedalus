# Phase 1: Thread Safety & Execution - Execution Plan

## Threat Model (ASVS L1)
**Authentication/Authorization:** No external network endpoints exposed; LLMs communicate via TLS to standard provider APIs. LLM output does NOT have privilege escalation vectors outside the GUI process permissions.
**Data Validation:** Ensure all LLM-returned code strings are syntactically valid before attempting `exec()` to prevent arbitrary crash exploitation or injection (EXEC-02).
**Concurrency Risks:** Enforce strictly QThread signals for FreeCAD document mutations to guarantee macOS compatibility and prevent memory corruption.

## Must Haves
- `RAGService` must no longer import `langchain` or `numpy` or `GoogleGenerativeAIEmbeddings`.
- `RAGService.get_full_context()` must return all `.md` files in `docs/api/` as a single multi-kilobyte string and store it in memory.
- `ContextInjector.get_developer_context()` must append the output from `get_full_context()` directly into the Developer's prompt.
- FreeCAD interaction (EXEC-03) through `command_executor.py` must reliably mutate the FreeCAD document via proper Qt mechanisms (the existing `execute()` structure that dispatches to the main event loop).
- Code blocks generated by the LLM must be syntactically validated before execution (EXEC-02).
- The Copilot LLM network queries must occur on the worker thread, actively streaming tokens to the UI (EXEC-01, UX-01).
