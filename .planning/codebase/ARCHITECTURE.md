# ARCHITECTURE

## Macro Architecture
The application is a multi-agent Copilot integrated directly as a FreeCAD Workbench. It follows a layered approach: UI Layer -> Orchestrator -> Sub-Agents -> Execution Engine -> FreeCAD Core.

## Core Components
### 1. Multi-Agent System (`agents/`)
- **`orchestrator.py`**: The central routing "brain". Receives human input, analyzes the intent, and delegates tasks to specific agents using output routing tags (`> **NEXT_AGENT:**`).
- **Domain Agents**: Include `developer_agent`, `designer_agent`, `validator_agent`, and `reviewer_agent`. Each handles specific phases of code generation, verification, or structural analysis.
- **System Control**: `system_controller.py` likely manages state transitions for the agent graph/workflow.

### 2. Execution Engine (`core/`)
- **`command_executor.py`**: Safely evaluates the Python scripts generated by the LLM. Features thread-boundary crossing to ensure FreeCAD commands are dispatched securely to the Qt Main Thread to avoid segfaults.
- **`rag_service.py`**: An offline/online retrieval-augmented generation service targeting FreeCAD's specific API surface to prevent the LLMs from hallucinating legacy methods.

### 3. User Interface (`ui/` & `Mod/`)
- Custom-built PySide2 components (Widgets, Tabs, Chats).
- Wrapped inside a `CopilotWorkbench` to render natively in FreeCAD's interface framework.
